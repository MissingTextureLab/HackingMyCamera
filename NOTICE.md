# Third-party notices

## data-mosh

The datamosh decoder (`decode` in `src/ops/registry.ts`) is a WGSL port of
`mainImageShader` from [niccolofanton/data-mosh](https://github.com/niccolofanton/data-mosh)
(`datamosh-demo/src/datamosh/shaders.ts`), with its trigger and recovery logic
(`datamosh-demo/src/datamosh/index.ts`) and default values (`datamosh-demo/src/debug.ts`).
Only source code is used; none of that repository's assets.
